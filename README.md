<h1 align="center">mpv.win</h1>

mpv.win is a video player for Windows 11, powered by mpv. It brings your videos,
playback controls, and settings together in a user-friendly way with a modern UI.

## Differences between mpv.win and mpv

mpv.win uses mpv to handle video, audio, and subtitle playback. It adds an
interface designed for Windows 11, with a library for your videos and settings
you can change inside the app.

The main additions are a browsable library with thumbnails, search, favorites,
and recent videos, along with "Windows-style" menus and controls. You can choose
your subtitle appearance, audio preferences, and interface colors through
the configuration menu, with a preview for subtitle styling as well.

mpv remains the playback engine; mpv.win provides the window, library, and
everyday controls around it. Simple as that.

## Features added to mpv.win

**GUI Interface for Configuration**

Configure video, audio, subtitles, and playback through dedicated settings
pages, without needing to edit mpv configuration files. The option is still
there though, if you wish.

**A modern Windows interface**

A native WinUI interface with light, dark, and Windows system themes.
You can customize the interface colors, including the seek bar and volume slider.

**Video library and search**

Browse your videos with thumbnails, recent videos, favorites, and pinned
folders. Add your own folders, exclude unwanted locations, and search the
videos cataloged in your library by name or folder.

**Subtitle styling made easier**

Adjust subtitle fonts, size, colors, outlines, position, and drop shadows
through the GUI in configuration. A sample preview shows your choices before you apply
them to playback.

**A much better looking OSC**

On-screen controls for seeking, looping, fullscreen, audio, and subtitles, all modernized
to make the OSC feel better. You can also use your keyboard to navigate around it without
any problems.

**File Explorer integration**

You can register mpv.win through the Configuration GUI to make it available
in Windows context menu. Simple as that.

**And a lot, lot more**

Everything you loved about mpv, is still there.

## What you need

- **Windows 11, 64-bit.**
- **.NET 10 runtime** for the current preview.

## Feedback and contributions

Bug reports, suggestions, and code contributions are welcome. If something
goes wrong, describe what you were doing, what you expected, and what happened.
For playback problems, include the video format and any error message you saw.
A screenshot or short recording helps with interface problems.
